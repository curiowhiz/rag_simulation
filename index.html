1 Knowledge Base Input

Number of chunks — controls retrieval granularity

2 Vector Embeddings — the core concept

Each chunk becomes a vector — a list of numbers capturing its meaning, not its words. Similar meaning = nearby vectors. Every colored cell below is one dimension of that vector.

3 Query

Ask a question. It gets embedded the same way the chunks were, so it can be compared against them.

4 Retrieval — vector similarity search

Every chunk is scored against the query by cosine similarity. The closer to 1.0, the more relevant.

Run the RAG system above to see scores.
